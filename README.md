# joseantoniocgonzalez-portfolio

Portfolio personal generado como sitio estático con HTML, CSS, JS, Jinja2 y Python.

## Estructura inicial

- `templates/`: plantillas
- `static/`: CSS, JS e imágenes
- `data/`: proyectos, artículos y certificaciones en JSON
- `dist/`: salida generada
- `build.py`: generador del sitio
